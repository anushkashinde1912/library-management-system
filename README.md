# Library Management System 📚

A Java-based Library Management System developed as an academic project to practice fundamental Data Structures and Algorithms.

## Features

- Add and manage book records
- Search for books by ISBN
- Search for books by author
- Sort books by ISBN
- Display book details

## DSA Concepts Used

- Linear Search
- Binary Search
- Bubble Sort
- Insertion Sort
- Quick Sort

## Technologies

- Java
